# Dorehami — دورهمی

**Discover together.** · «چیزهای تازه، آدم‌های تازه، دورهم.»

Dorehami is a bilingual (Persian/English) event-discovery and community platform. It combines two equal pillars: **event discovery & participation** and **community discovery & engagement**. It is not merely an event-listing website.

> **Current phase: Phase 0 — documentation only.** No application code, database, or infrastructure exists yet. See [docs/PROJECT-STATUS.md](docs/PROJECT-STATUS.md).

## How to read decision labels

Every document distinguishes: **Confirmed** (given in the Phase 0 brief or explicitly decided), **Provisional** (recommended, needs validation), and **Open** (unresolved, tracked in PROJECT-STATUS.md). Assumptions are never presented as facts.
